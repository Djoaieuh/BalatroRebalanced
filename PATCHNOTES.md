# Balatro Rebalanced - v1.0.0 

**This file lists all the differences between the Balatro Rebalanced Mod and Vanilla Balatro**

- New : "**+100** Chips if played hand contains a Two Pair"

- New : "Gains **+20** Chips if played hand contains a Straight"

Vampire : 
- Old : "Gains X0.1 Mult per scoring Enhanced card played, removes card Enhancement"
- New : "Gains **X0.2** Mult per scoring Enhanced card played, removes card Enhancement"

Superposition : 
- Old : "Create a Tarot card if poker hand contains an Ace and a Straight"

Onyx Agate : 
- Old : "Played cards with Club suit give +7 Mult when scored"
- New : "Retrigger any played Clubs"

Marble : 
- Old : "Adds one Stone card to the deck when Blind is selected"
- New : "On the first hand of each round turn the 2 lowest ranked cards into Stone Cards"

Loyalty Card : 
- Old : "X4 Mult every 6 hands played"
- New : "After 6 hands played, stores X4 Mult. When rightmost, cashes out and destroys itself"

Hanging Chad : 
- Old : "Retrigger first played card used in scoring 2 additional times"
- New : "Retrigger the first and last played card in scoring"

Cloud 9 : 
- Old : "Earn $1 for each 9 in your full deck at end of round"
- New : "Earn $1 for each 9 you played this round and each 9 in your full deck at end of round"

Erosion : 
- Old : "+4 Mult for each card below the deck's starting size in your full deck"
- New : "Destroys 1 scored Stone Card per hand to gain X0.25 Mult"

Throwback : 
- Old : "X0.25 Mult for each Blind skipped this run"
- New : "Once per round, after you skip a Booster Pack, open another of the same type"

Glass Joker : 
- Old : "This Joker gains X0.75 Mult for every Glass Card that is destroyed"
- New : "Glass cards now have a 1 in 2 chance to break but give X3 Mult"

Merry Andy : 
- Old : "+3 discards each round, -1 hand size"
- New : "Gives +3 discard and -1 Consumable slot"

Steel Joker :
- Old : "X0.2 Mult for each Steel Card in your full deck"
- New : "Whenever you discard, you will always draw at least 1 Steel Card"

Stone Joker : 
- Old : "Gives +25 Chips for each Stone Card in your full deck"
- New : "Stone Cards can form Poker Hands"

Flower Pot : 
- Old : "X3 Mult if poker hand contains a Diamond card, Club card, Heart card, and Spade card"
- New : "After playing 25 cards of the same suit in a row, transforms into that suit's Flower Pot"

Hearts Flower Pot (NEW) : 
- "+4 handsize"

Clubs Flower Pot (NEW) : 
- "Copies ability of Joker to the right"

Spades Flower Pot (NEW) : 
- "+1 Voucher available in the shop each Ante"

Diamonds Flower Pot (NEW) : 
- "Your Enhancements, Seals and Editions trigger an extra time"

Satellite : 
- Old : "Earn $1 at end of round per unique Planet card used this run"
- New : "At end of round, gain $1 for each Pair level you have. After you play a Pair, this changes hand" 
*(This is not always on Pairs, the hand is chosen randomly every time)*

Shoot the Moon :
- Old : "Each Queen held in hand gives +13 Mult"
- New : "If the first card in your played hand is a Queen, convert all other cards to the Queen's suit"

Campfire : 
- Old : "Gains X0.25 Mult for each card sold, resets when Boss Blind is defeated"
- New : "After you sell a Planet gain X0.25 Mult and change target. Selling anything else resets this Joker to X1 Mult"
*(Target cycles between Jokers, Tarot cards and Planet cards)*

Matador : 
- Old : "Earn $8 if played hand triggers the Boss Blind ability"
- New : "When Boss Blind is selected, gain +3 Hands"

## Vouchers

- Old : "Foil, Holographic, and Polychrome cards appear 2X more often"
- New : "Uncommon Jokers are X2 as likely to appear"

Glow Up : 
- Old : "Foil, Holographic, and Polychrome cards appear 4X more often"
- New : "Rare Jokers are X2 as likely to appear"

Magic Trick : 
- Old : "Playing cards can be purchased from the shop"
- New : "Playing cards can be purchased from the shop and may have an Enhancement, Edition and/or Seal"

Illusion : 
- Old : "Playing cards can be purchased from the shop and may have an Enhancement, Edition and/or Seal"
- New : "Every 5 rerolls, spawn a Booster Pack in the shop"

Planet Merchant : 
- Old : "Planet cards appear 2X more frequently in the shop"
- New : "Planet cards now upgrade your poker hands by an extra level"

Planet Tycoon : 
- Old : "Planet cards appear 4X more frequently in the shop"
- New : "Whenever you use a Planet card in the Shop, reduce the reroll cost by $1"

### Spectral Cards

- New : "Destroys 4 random cards in hand, gain $10"

Incantation :

- New : "Destroy a card and add its rank to its neighbours"

- Old : "Destroy 1 random card in your hand, add 3 random Enhanced face cards to your hand"
- New : "Destroy 2 random cards and convert 3 into random Enhanced face cards"

Grim : 
- Old : "Destroy 1 random card in your hand, add 2 random Enhanced Aces to your hand"
- New : "Add a random Enhanced Ace to your hand and create 2 random Negative Tarot cards"

Black Hole :
- Old : "Upgrade every poker hand by 1 level"
- New : "+2 hand size, you can no longer play your most played hand"

Ouija : 
- Old : "Converts all cards in hand to a single random rank -1 hand size"
- New : "Converts all cards in hand to a single random rank. They are debuffed until next Ante"

Hex : 
- Old : "Add Polychrome to a random Joker, destroy all other Jokers"
- New : "Add Polychrome to your right-most Joker and make it Eternal"
